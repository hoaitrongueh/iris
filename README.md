# iris

My Arch Linux desktop with Hyprland, a customized Caelestia shell, Kitty, and Zen. Monochrome glass, floating terminals, a compact application rail, and an eerie moon live wallpaper.

## terminals first

System identity. Dotfiles. Live vitals.

![Three frosted Kitty terminals showing Arch system info, the iris config tree, and live CPU and memory graphs against the moonlit wallpaper](demo/terminals.gif)

## work in progress

RELIC's inverse kinematics, in C++. Code on the left; source and test discovery on the right.

![VS Code showing RELIC's C++ inverse-kinematics solver beside terminals with the source tree and CTest test inventory](demo/workflow.gif)

## one keystroke away

`Super+G` toggles the dashboard. `Super+Shift+G` opens Overview; `Ctrl+Super+G` opens System. Moon still in view.

![Overview and System dashboard views switching below the moon, with media, calendar, and live resource information](demo/dashboard.gif)
